# Empires: Хроники Эльдора

Пошаговая тактическая стратегия в духе Ancient Empires 2 для браузера. Vanilla JS + Canvas, без сборки и зависимостей. Рассчитана на вертикальный экран телефона: карта целиком помещается на экран без прокрутки.

**Играть:** https://wiverhome.github.io/empires/

## Локальный запуск

```bash
node tools/serve.js
```

Затем открыть http://localhost:5173. Открыть `index.html` как файл не получится: браузер запрещает читать пиксели картинок с `file://`.

## Что есть

- Кампания из 8 миссий в двух главах, с диалогами и событиями (в том числе сопровождение кристалла).
- Схватка на 6 картах и на своих картах из редактора: до 4 сторон, любая сторона за игрока или ИИ, игра вдвоём на одном телефоне, туман войны по желанию.
- 11 типов наёмных воинов: яд паука, аура огонька, водяные на воде и мелководье, катапульты, разрушающие деревни. Призраки из могил, командиры с уровнями.
- Захват деревень и замков, руины, которые можно отстроить, доход, найм, лечение на зданиях.
- ИИ противника с тремя уровнями сложности, автосохранение в браузере.

## Инструменты

- `node tools/check-maps.js` - проверка карт миссий.
- `node tools/sim.js --runs 20` - ИИ против ИИ на всех миссиях (поиск зависаний и грубый баланс).
