# Empires: Хроники Эльдора

Пошаговая тактическая стратегия в духе Ancient Empires 2 для браузера. Vanilla JS + Canvas, без сборки и зависимостей. Рассчитана на вертикальный экран телефона: карта целиком помещается на экран без прокрутки.

**Играть:** https://wiverhome.github.io/empires/

## Локальный запуск

```bash
node tools/serve.js
```

Затем открыть http://localhost:5173. Открыть `index.html` как файл не получится: браузер запрещает читать пиксели картинок с `file://`.

## Что есть

- Кампания из 12 миссий в трёх главах, с диалогами и событиями (сопровождение кристалла, оборона мостов, боссы). За победу - до трёх звёзд.
- Схватка на 11 картах и на своих картах из редактора: до 4 сторон, любая сторона за игрока или ИИ, игра вдвоём на одном телефоне, туман войны по желанию. Своей картой можно поделиться кодом.
- 13 типов наёмных воинов: яд паука, сковывание шамана, волки, которым лес не помеха, аура огонька, водяные на воде и мелководье, катапульты, разрушающие деревни. Призраки из могил, командиры с уровнями.
- Захват деревень и замков, руины, которые можно отстроить, доход, найм, лечение на зданиях.
- ИИ противника с тремя уровнями сложности, автосохранение, отмена действий в пределах хода.
- Достижения и повторы последних партий.
- Музыка и звуки (CC0, см. `assets/CREDITS.md`).

## Android

Нативное приложение на Kotlin + libGDX (без WebView) лежит в `android/`:

- `android/logic` - правила, ИИ, кампания и схватка, перенесённые из `js/` один к одному.
- `android/app` - графика, интерфейс, звук, сохранения и игра вдвоём на двух телефонах рядом: через Nearby Connections (Bluetooth, Wi-Fi Direct) или в одной сети Wi-Fi (автопоиск либо адрес вручную). Интернет не нужен.

Картинки и звуки берутся из общей папки `assets/`. Сборка (нужны JDK 17 и Android SDK, путь к SDK - в `android/local.properties`):

```bash
cd android && ./gradlew :app:assembleDebug
```

APK появится в `android/app/build/outputs/apk/debug/`. Нужен Android 8.0 или новее.

Релиз для публикации: `./gradlew :app:assembleRelease`. Ключ подписи и пароли берутся из `android/local.properties`
(`release.storeFile`, `release.storePassword`, `release.keyAlias`, `release.keyPassword`); ни ключ, ни этот файл в git не попадают.
Без ключа релиз подписывается отладочным ключом. Потеря ключа означает, что обновить приложение в магазине будет нельзя: храните резервную копию.

## Инструменты

- `node tools/check-maps.js` - проверка карт миссий.
- `node tools/sim.js --runs 20` - ИИ против ИИ на всех миссиях (поиск зависаний и грубый баланс). С `--replay` каждая партия ещё и проигрывается заново из журнала, итог должен совпасть.
- `cd android && ./gradlew :logic:run --args="--runs 3"` - та же симуляция на Kotlin. Вывод обязан совпадать с `node tools/sim.js --runs 3`: так проверяется, что правила в двух версиях одинаковые.
